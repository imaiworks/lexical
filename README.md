# Lexical

**フレーズで入って、フレーズを広げて、フレーズから文法を知る。**  
旅行・仕事・日常、すぐ使える英語を Lexical Approach で。

🔗 https://imaiworks.github.io/lexical/

---

## なぜ Lexical なのか

従来の英語学習は「文法を学ぶ → 例文を覚える → 使ってみる」。  
でも多くの人は文法を学んでも、とっさに言葉が出てこない。

Lexical はその逆を行く。

1. **フレーズで入る** — 場面ごとの定番チャンクから始める
2. **フレーズを広げる** — 置き換え・関連表現・返し方へ枝葉を伸ばす
3. **フレーズから文法を知る** — 使ったフレーズの構造を、使った後で理解する

文法はゴールじゃなくて、フレーズを深く使うための道具。

---

## 機能

- **心構えカード** — その場で何が起きるか、相手から来る言葉・自分が言う言葉を事前確認
- **枝葉展開** — チャンクから関連表現・パターン・返し方へ広がる
- **指差し英会話** — 返答例を相手に見せて指差ししてもらえる
- **ネイティブ発音** — タップ一発で Web Speech API が即再生
- **文法解説** — 使ったフレーズをSVO構造で色分け表示
- **練習モード** — 日→英 / 英→日 のフラッシュカードで反復練習
