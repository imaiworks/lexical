# Lexical

Scene-based English chunk app for travelers — learn phrases, not grammar.

旅行・日常英会話を「チャンク」で学ぶWebアプリ。8シーン・350フレーズ収録、心構えカード＋ネイティブ発音対応。

🔗 https://imaiworks.github.io/lexical/

## シーン一覧

✈️ 空港 / 🏨 ホテル / 🍽️ レストラン・カフェ / 🛍️ ショッピング  
🚕 交通・移動 / 🗺️ 観光 / 🆘 緊急・トラブル / 💬 日常会話

## 特徴

- **心構えカード** — その場で何が起きるか、相手から来る言葉・自分が言う言葉を事前確認
- **枝葉展開** — チャンクから関連表現・パターン・返し方へ広がる
- **指差し英会話** — 返答例を相手に見せて指差ししてもらえる
- **ネイティブ発音** — タップ一発でWeb Speech APIが即再生

## 技術スタック

Vanilla HTML / CSS / JavaScript + JSON — ビルド不要、静的ファイルのみ
